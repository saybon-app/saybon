Talkletics landing update

1. Unzip over the project root (the folder that contains "public"), replacing files:
   unzip -o talkletics-landing-update.zip      (Windows: right-click > Extract All, overwrite)

2. Git + deploy (pushing to main deploys hosting through the GitHub Action):
   PowerShell:  .\deploy.ps1
   Bash:        bash deploy.sh
   Or by hand:
     git add public/talkletics
     git commit -m "Talkletics landing: static header/button, home + dashboard buttons, smoother scenes"
     git push origin main
   Or deploy without GitHub:
     firebase deploy --only hosting --project saybon-3e3c2

Alternative to unzipping: git apply --ignore-whitespace talkletics-landing.patch
